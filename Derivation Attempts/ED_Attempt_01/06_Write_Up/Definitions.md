# Definitions

*Short explanations of the main terms used in the Event Density (ED) write-ups. Grouped by topic; ledger references in brackets for anyone who wants the detail.*

## The picture

| term | meaning |
|---|---|
| **Event Density (ED)** | A picture of the world as a growing web of places where time runs one way and things become definite through irreversible events |
| **Locus (plural: loci)** | One place in the web. The smallest unit of "where" |
| **Channel** | A slot at a locus that a pattern can occupy. ED's test rules use an *Internal* channel plus one *lane* for each direction of travel |
| **Lane** | A channel for moving in a particular direction (for example, a Right lane and a Left lane) |
| **Pattern** | Something spread across loci and channels before it becomes definite, like a wave. Amounts in a pattern work like probabilities |
| **Spreading** | How a pattern moves across the web, trying many paths at once. It is reversible |
| **Primitives** | ED's starting assumptions, numbered P01–P13 (for example P11: commitment is irreversible) |
| **Contrast First Ontology** | The philosophy behind ED: relations come from differences, and a single thing on its own has no relations ("one is none") |

## Commitment and measurement

| term | meaning |
|---|---|
| **Commitment** | A step that can't be taken back. The basic "something really happened" event in ED. It leaves no stored record at a locus; it changes what exists [D1] |
| **Meeting** | When a pattern encounters another pattern or settled matter. A meeting by itself changes nothing irreversibly; the two simply become linked [RD27] |
| **Hinge** | Two patterns becoming one joint pattern after a meeting, still reversible |
| **Mark** | The trace a meeting leaves in the other party that tells which way the pattern went |
| **Record** | What a mark says, for example "the pattern went left" |
| **Draw** | The moment a mark can no longer be brought back, so the outcome becomes final. A draw fixes only what the mark recorded [RD28, RD50] |
| **"Can't be brought back"** | ED's meaning: part of the mark has gone beyond the reach of every future path, beyond the horizon [RD50] |
| **Horizon** | The boundary beyond which nothing can ever return to us, set by the universe's accelerating expansion |
| **10¹²²** | Roughly how many distinguishable states the horizon can hold. It sets how exact a draw can be. It is also, by arithmetic, the size of the cosmological constant in natural units |
| **Redundancy** | A mark copied into several independent pieces of matter. Used in simulations as a practical stand-in for "beyond the horizon" |
| **Interference** | A pattern reinforcing or cancelling itself by taking more than one path |
| **Quantum eraser** | An experiment where removing which-path information brings interference back |
| **Decoherence** | The loss of interference when information about a system spreads into its surroundings |

## Gravity and the universe

| term | meaning |
|---|---|
| **Budget** | How much commitment a locus has used up. Near settled matter the budget is more used, and everything there slows down [RD14, RD35–RD37] |
| **Slowing** | Clocks and internal change slow by one factor of the budget; moving between loci slows by twice that. This is how ED matches gravity |
| **General relativity (GR)** | Einstein's theory of gravity. ED's budget, once adjusted to measurements, matches it |
| **Locus birth** | New loci being added to the web at a steady rate everywhere [RD43] |
| **Birth chance** | The probability a new locus is born, per locus per step. ED's one free number, about 2.9 × 10⁻⁶¹ per Planck step |
| **Dark energy / cosmological constant (Λ)** | The steady push that makes the universe's expansion accelerate. In ED it comes from locus birth |

## Handedness

| term | meaning |
|---|---|
| **Handedness** | A built-in preference for one direction (left or right) over the other |
| **Mirror symmetry** | Rules that look the same when left and right are swapped. ED's rules have it [A1] |
| **Time-reversal symmetry** | Rules that look the same when the direction of time is flipped. One-way time can break it |
| **Winding number** | A whole number that measures net handedness in how patterns move. Zero means no net preference [C1–C4] |
| **Handedness theorem** | ED's proved result: mirror-symmetric rules have zero winding, so any handedness must be picked by the state |
| **Two-way symmetric (reciprocal)** | Transport where moving one way looks the same as moving back. ED's spreading is like this, which blocks handedness on its own [C269, C275] |
| **Lane loop** | The smallest loop in ED's rules: hop along one lane, switch lanes, hop back, switch back |
| **Standing phase** | A fixed phase around a lane loop that is neither 0 nor a half-turn. The ingredient ED's handedness needs and ED couldn't supply [C288, C303] |
| **Coherence** | Part of ED's stability score (P12): how well phases fit together around small loops |
| **Frustration** | When competing loops can't all be satisfied at once, forcing in-between values; can pick a direction by chance |

## How the work was done

| term | meaning |
|---|---|
| **Ledger** | The running record of everything: claims, decisions, definitions, and a dated log (`01_Ledger`) |
| **Claim (C number)** | A single statement, with its status and evidence |
| **Claim status** | *PROVED* (mathematics); *COMPUTED* (a script anyone can rerun); *CITED* (checked against a published source); *CONDITIONAL* (holds if its inputs hold); *OPEN* (not settled) |
| **Rule decision (RD number)** | A choice about what ED means, made by Allen from options, with the reasons |
| **Definition (D number)** | Allen's own statement of an idea, recorded in his words |
| **Gap (G number)** | An open question waiting for a decision |
| **Check** | A script that reruns a result and confirms it still comes out the same |
| **Literature check** | Searching published work before making a claim, to avoid rediscovering or contradicting known results |
| **Tuned setting** | A value chosen to make something work. Always labelled, never counted as ED's own content |
| **Stand-in (modelling choice)** | A practical substitute used in simulations that isn't part of ED itself, for example redundancy standing in for the horizon |
| **Exit rule** | An agreement made in advance: if three honest attempts to make ED supply a missing ingredient fail, stop and write ED up as it stands [RD52, RD55] |
| **Review packet** | A summary of the handedness theorem prepared for an outside physicist to check (`05_Outside_Review`); sent only if Allen decides |

# What's worth keeping

- **The arrow in the law, through irreversible commitment.** It's your best idea, a real philosophical position, and the one ingredient your result needed.
- **A uniform start plus a first difference.** There's a sharp point hidden in this. A deterministic rule with no preferred direction, run on a perfectly uniform state, keeps it uniform forever. So the first difference has to come from one of three places:
  - randomness in the rule
  - a rule that isn't symmetric
  - a start that wasn't really uniform

  Choosing among them is a precise decision. It also has the same shape as your theorem: asymmetry comes from the state or from chance, never from symmetric rules.
- **The package: process, relational, discrete, irreversible.** It holds together, provided each word gets one definition that stays fixed.

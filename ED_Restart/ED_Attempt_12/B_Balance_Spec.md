# The balance point: is there a rate at which the shape stops drifting?

*ED_Attempt_12, note 5. 2026-09-23 (RD7). Ledger: C6. Specification; nothing computed. From Allen's reading of ED's inflation language. Written plainly.*

## Where this comes from

ED's own cosmology summary says inflation-like behaviour is **"event-structure complexity outpacing event-production capacity"** (ED-Orientation, the ED-08 / 00.1 summary). Allen's recall of it — *production of events outpacing production of space* — points at the same thing with the terms swapped, and at something we have now seen three times:

- **too few relations per event** → a chain. One dimension. Nothing knits together.
- **too many** → everything touches everything. A small world, no dimension.
- **three is somewhere in between**, and every setting we've tried has *drifted* through it rather than settling on it.

**So the question is not "what value gives three?" but "is there a rate at which the reading stops moving as the pattern grows?"** A shape that holds still as it grows is a shape; one that drifts is on its way somewhere else.

## The picture

**What would be built:** the same generation growth as road P — events pass on once and are spent, children inherit their parents' neighbourhoods — but with one knob: **how many relations each new event arrives with.** Call it ρ. The filter is switched **off**, so nothing else interferes; this is purely about whether relations keep pace with events.

**What would be read:** the dimension reading at two sizes, and the **drift** between them.

**What the outcomes would mean:**

| what we'd see | what it means |
|---|---|
| **The drift is upward at every ρ** | No balance point. Relations always win eventually, and every pattern is on its way to a small world. The idea closes |
| **The drift is downward at small ρ and upward at large ρ**, crossing zero somewhere | **A balance point exists.** At that rate a shape holds still as it grows. Then: what does it read? |
| **A balance point exists and reads between 2.5 and 3.5** | The strongest thing this project could still find: a rate at which ED's growth holds a three-dimensional shape steady |
| **A balance point exists and reads 1.5, or 5** | It exists, and it isn't three. Honest, and it kills "fewest directions picks three" for good |

## Expected results, fixed before any code

| | expectation | confidence |
|---|---|---|
| **B1** | A balance point exists — the drift changes sign as ρ varies | **About 50%** |
| **B2** | If it exists, the reading there is between 2.5 and 3.5 | **About 25%** |
| **B3** | Reported, no expectation: the drift at each ρ, what each one settles on, and whether the two starts agree |

## The honest cost, stated before the run

**ρ is a dial.** If a balance point exists at ρ = 4.3 and reads three dimensions, that is **not** a derivation of space unless ED supplies 4.3 from something it already says. Under the census guard it would be **one more input, not one fewer** — unless it turns out that ED's link budget (6.699) or its ceiling already fixes it, which is exactly the thing worth looking at if a balance point is found.

**What would make it more than a dial:** if the balance point is the *only* rate at which a shape is stable, then ED doesn't need to supply a value — stability itself picks it. That is the version worth having, and it's why the test reads drift rather than dimension.

## The test

- **Knob:** ρ, the relations per event the growth holds to, scanned over 2, 3, 4, 5, 6, 8.
- **Starts:** a ring and a 3D grid — two shapes as different as we have — at about 2,000 events, two seeds each.
- **Grown** to four times the starting size, with the reading taken at two sizes along the way.
- **Drift** = the change in the reading between those two sizes, judged against a real shape of the same kind at the same size, as in road P.
- **Balance point** = where the drift crosses zero, if it does.
- **Cost:** the filter is off, so these are the fast runs — well under an hour.

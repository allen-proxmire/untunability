# Way forward 1: maximum uniformity, zero contrast

## The idea

Start from a world with no differences at all: maximum uniformity, zero contrast. Let the first difference appear, and watch what grows from it.

The instinct behind it is the one in Penrose's conformal cyclic cosmology: the very beginning and the very end of the universe are both featureless. ED's version asks what the smallest step away from featureless looks like, and what it leads to.

## Why it's worth doing

- **It matches the commitments.** Events are basic, commitment is irreversible, relations come first, and the world is discrete ([Core_Commitments.md](../03_Philosophy/Core_Commitments.md)).
- **It is Rule 1 exactly.** State: uniform. First difference: one site differs. Rule: how a difference spreads and can't un-spread. Run: watch what grows ([the rules](../00_Rules/README.md)).
- **It starts from nothing you have to defend.** A uniform state has no parameters to tune.

## The sharp point: the fork

A deterministic rule with no preferred direction, applied to a perfectly uniform state, keeps it perfectly uniform forever. So a first difference has to come from one of three places:

| option | what it means | what it costs |
|---|---|---|
| **Chance** | The rule has a random element (a commitment picks among options). | Probabilities must be part of the rule from the start. |
| **A lopsided rule** | The rule itself prefers something. | The asymmetry is put in by hand, so nothing about its origin is explained. |
| **A non-uniform start** | The world was never really uniform. | The "first difference" is an initial condition, not an event. |

Choosing among these is the first real decision. ED's commitments (symmetric rules, an arrow) point to chance. See [Merged_Uniformity_Irreversibility.md](Merged_Uniformity_Irreversibility.md).

## Traps to avoid

- **Inserting the first difference by hand.** Putting one odd site in "to get things going" is the non-uniform start in disguise. Say so if you do it.
- **Mistaking generic behaviour for a discovery.** Spreading, smoothing, relaxation and oscillation appear in almost any rule (Rule 4). Growth from a seed is not evidence of anything by itself.
- **Treating the CCC parallel as evidence.** It is a resemblance of pictures, not a calculation.
- **Renaming.** "The first difference is the birth of spacetime" is a sentence, not a result.

## Nearest existing work

- **Causal set sequential growth** (Rideout and Sorkin, 1999). A universe grows from nothing, one event at a time, with each new event placed by probabilities. It is the closest existing rule to this idea, and it already takes the chance option.
- **Conformal cyclic cosmology** (Penrose, *Cycles of Time*, 2010). The featureless beginning and end.

## First steps

1. Choose the fork option, and write down why.
2. Write the rule as something a computer can run, before any interpretation.
3. Decide in advance what counts as "something grew": a measured quantity with a threshold.
4. Run the same analysis on a deliberately different rule (Rule 3).
5. Learn the sequential growth model and state where this rule differs from it.

## Open questions

- If chance drives everything, where do the probabilities come from, and are they part of the rule or of the state?
- Does a difference, once it appears, persist because of irreversibility, or wash out?
- What is the smallest rule in which anything more than spreading happens?

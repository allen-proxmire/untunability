# Event Density: core commitments

*Draft, September 2026*

This page states what Event Density commits to about the world. These are commitments, not results. Nothing here is derived, and none of it shows that known physics follows. Each commitment is placed next to the existing position it most resembles, so it can be judged against work that already exists.

---

## Terms

Each word below has one meaning, used the same way everywhere on this page.

| term | meaning |
|---|---|
| **event** | The basic unit. An event has no size, duration or location of its own. |
| **relation** | A link between two events. For now, the only relation is precedence: one event comes before another. |
| **commitment** | The adding of an event to the world. Once added, an event cannot be removed and its relations cannot change. |
| **becoming** | The ongoing adding of events. |
| **region** | A set of events picked out by their relations to one another. |
| **event density** | The number of events in a region. It is a count, not a rate, because there is no background time to divide by. |
| **arrow** | The order in which events are committed. |

Words from earlier ED papers not used here, because they never had one fixed meaning: *participation, bandwidth, thick/thin, channel, gradient of becoming.*

## The commitments

### C1. Events are basic

The world consists of events, not enduring things. An enduring object (a particle, a planet, a person) is a stable pattern of events.

*Nearby:* process philosophy. Whitehead, *Process and Reality* (1929); J. Seibt, "Process Philosophy", *Stanford Encyclopedia of Philosophy*.

### C2. Commitment is irreversible, and the arrow is in the basic rule

Events are added one at a time and never removed. The direction of time is this order of adding. The arrow is a feature of the basic rule, not a statistical tendency and not a consequence of a special starting state.

> **Note 2026-09-13 (conflict with D1).** Allen's definition of commitment (ledger D1): a commitment is a step a chain can't take back, **not a record kept anywhere**; loci are reused and keep no memory. This section's wording ("events are added one at a time and never removed", and in Terms, "once added, an event cannot be removed") describes a growing record, which D1 rejects. It needs rewriting before this draft is used. Not rewritten yet, so the change can be Allen's. **Update 2026-09-13:** Allen's idea that space is the record (D8, decision G28) may reverse this conflict. Under G28 (a), commitments leave space behind but no memory.

*Nearby:* L. Smolin and R. M. Unger, *The Singular Universe and the Reality of Time* (2014); G. F. R. Ellis's "evolving block universe"; T. Maudlin, *The Metaphysics Within Physics* (2007).

### C3. Events are defined by their relations

An event has no properties apart from its relations to other events. Two events with the same relations are not two different kinds of thing.

*Nearby:* C. Rovelli, "Relational Quantum Mechanics" (1996); structural realism, J. Ladyman and D. Ross, *Every Thing Must Go* (2007).

### C4. The world is discrete

Events can be counted. Space, time and geometry are approximations that hold when very large numbers of events are described together.

*Nearby:* causal set theory, whose slogan is "order + number = geometry". L. Bombelli, J. Lee, D. Meyer and R. Sorkin, "Space-time as a causal set" (1987).

### C5. Familiar laws are regularities of the basic rule

There is one basic rule: the rule by which events are committed. Newton's, Maxwell's and Einstein's laws are not further basic rules. They are stable large-scale regularities in how that one rule plays out.

*Nearby:* J. A. Wheeler, "law without law"; L. Smolin, *Time Reborn* (2013).

### C6. A measurement outcome is a committed record

An outcome is definite when events recording it have been committed. Nothing about observers or consciousness is involved.

*Nearby:* Bohr's emphasis on irreversible amplification; M. Gell-Mann and J. B. Hartle, "Classical equations for quantum systems" (1993).

## The closest existing framework

R. Rideout and R. Sorkin, "A classical sequential growth dynamics for causal sets" (1999). The universe grows one event at a time. Each new event is placed after some existing events, and the growth is irreversible. C1, C2, C3 and C4 are all built into it.

The obvious next step is to learn this model and ask where ED would differ from it. If it would not differ anywhere, ED is this model, and that is fine.

## Choices not yet made

These commitments leave open decisions that must be settled before anything can be calculated.

1. **Where does the first difference come from?** A deterministic rule with no preferred direction, applied to a perfectly uniform state, keeps it uniform. So one of these must hold:
   - the rule contains randomness;
   - the rule is not symmetric;
   - the start was not uniform.
2. **What exactly is the rule?** Which existing events does a new event come after, and with what probabilities, if any?
3. **Is precedence the only relation?** C3 allows only precedence for now. Adding any other relation is a new commitment and must be listed here.
4. **How often does commitment happen?** Quantum systems evolve reversibly between measurements. If commitment happened constantly, nothing could stay in superposition. So commitment must be rare, or tied to records, and the rule must say which.

## Tests the commitments must pass

These are facts any version of ED has to agree with. Agreeing with them is not a result, but failing any one ends that version.

- **Bell's theorem.** Entangled pairs violate the CHSH inequality, up to 2√2. An account in which each half of a pair carries a rule set at creation and resolves it locally cannot do that.
- **Gravitational time dilation.** A clock lower in a gravity well records less elapsed time than one higher up, when the two are brought back together. Whatever ED says about gravity must get this sign right.
- **Lorentz invariance.** A regular grid of events picks out a preferred frame, and none is observed. Causal sets avoid this by placing events at random; see L. Bombelli, J. Henson and R. Sorkin, "Discreteness without symmetry breaking: a theorem" (2009). That bears directly on choice 1 above.
- **Reversible microphysics.** The known basic dynamics are, to very good approximation, the same run forwards and backwards. C2 has to explain how an irreversible basic rule looks reversible almost everywhere.

## What this page does not claim

- It does not claim that general relativity, quantum mechanics or cosmology follow from these commitments.
- It does not claim these commitments are the only coherent option, or the best one.
- It does not claim that any puzzle in physics is solved by them. A commitment that renames a puzzle has not solved it.

It claims only that these six commitments are consistent with each other, that each has serious company, and that they are definite enough to start building a rule from.
